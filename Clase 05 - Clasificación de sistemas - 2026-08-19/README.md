# Clase 05 — Clasificación de sistemas

### 1️⃣ 📘 Identificación

- **Tema principal:** clasificación de sistemas y niveles de los sistemas de información en las organizaciones.
- **Subtemas y actividades:** tipos de sistemas; datos e información; retroalimentación; sistemas de información; TPS, MIS y DSS; nivel estratégico; análisis de una aplicación móvil; investigación sobre ERP, CRM y sistemas expertos.
- **Propósito:** relacionar la estructura de los sistemas con las necesidades de información y toma de decisiones de una organización.

### 2️⃣ 📝 Resumen explicativo

**Clasificaciones y componentes.** La clase repasó la clasificación por relación con el entorno (abiertos, cerrados y aislados), naturaleza (conceptuales, materiales o híbridos), origen (naturales o artificiales), complejidad, comportamiento en el tiempo (estáticos o dinámicos) y naturaleza de sus resultados (deterministas o probabilísticos). La complejidad depende del enfoque y debe definirse con criterios claros. Se retomaron entradas, proceso, salidas, entorno y retroalimentación.

**Datos, información y retroalimentación.** Se explicó que un sistema puede recibir información ya procesada, aunque dentro del sistema esa entrada se trata como datos para producir una nueva salida. La retroalimentación consiste en usar resultados para ajustar el comportamiento. Puede ser automática, semiautomática o manual; en muchos sistemas deterministas requiere intervención de especialistas, por ejemplo para detectar registros duplicados y corregir el diseño de los datos.

**Sistemas de información.** Se describieron como conjuntos organizados de datos, personas, procesos y tecnología que recopilan, procesan, almacenan y distribuyen información. Deben tener un propósito claro y cambiar cuando las necesidades de usuarios u organizaciones cambian. El análisis de la aplicación móvil asignada debía identificar para qué sirve, qué cubre, qué no cubre, qué problemas tiene y cómo podría mejorarse; se indicó explorarla antes de contestar el cuestionario.

**Niveles organizacionales.** Se presentó una clasificación por nivel:

- **Operacional:** sistemas de procesamiento de transacciones (TPS) que registran actividades y datos cotidianos.
- **Táctico o administrativo:** sistemas MIS, que generan reportes periódicos, y DSS, que apoyan consultas o decisiones específicas menos frecuentes.
- **Estratégico o directivo:** integra datos y reportes para observar tendencias y apoyar decisiones generales.

La utilidad del nivel estratégico depende de la calidad de los datos capturados y de los reportes anteriores. Un error o sesgo en los registros puede producir análisis y decisiones incorrectos. Como investigación para la siguiente clase se pidieron tipos y ejemplos adicionales, como sistemas expertos, ERP y CRM.

### 3️⃣ 🧩 Conceptos teóricos y técnicos relevantes

- **TPS (Transaction Processing System):** registra y procesa transacciones habituales de la operación.
- **MIS (Management Information System):** prepara reportes periódicos que describen el estado de una organización.
- **DSS (Decision Support System):** apoya consultas o decisiones particulares con datos disponibles.
- **Nivel estratégico:** usa información agregada para identificar tendencias y orientar decisiones de dirección.
- **Datos e información:** los datos se procesan en un contexto para producir información con significado para un propósito.
- **Retroalimentación:** uso de salidas para corregir o ajustar el sistema.
- **Calidad de datos:** precisión y consistencia de los registros que alimentan reportes y análisis.
- **ERP y CRM:** nombres de categorías de sistemas empresariales que se dejaron para investigar; la clase advirtió que el marketing puede usar estas etiquetas de manera imprecisa.

### 4️⃣ ⚠️ Problemas, errores o aclaraciones del profesor

- Una misma aplicación puede parecer simple o compleja según el nivel que se analice; se debe declarar el alcance y el criterio usados para clasificarla.
- Los nombres TPS, MIS y DSS describen funciones o niveles de uso dentro de una organización; no necesariamente son las etiquetas que una empresa usa al presentar sus herramientas.
- La calidad deficiente de los registros puede sesgar reportes y decisiones posteriores.
- Durante la sesión aparecieron problemas de acceso y entrega en la plataforma para algunos estudiantes. El profesor pidió revisar los casos; la transcripción termina antes de documentar todas las soluciones.
- ⚠️ Parte del archivo parece incompleta o truncada en la transcripción.

### 5️⃣ 🧠 Conclusión de la clase

Los sistemas de información conectan la operación diaria con la administración y la toma de decisiones. Para que esa cadena produzca resultados útiles, hay que definir el propósito, clasificar correctamente el sistema, cuidar los datos y comprender la aplicación que se está analizando. La investigación de sistemas expertos, ERP y CRM quedó para la siguiente sesión.

### 6️⃣ ✅ Síntesis final

Los sistemas se clasifican con criterios distintos y según el contexto.
Los sistemas de información reúnen datos, personas, procesos y tecnología.
TPS registra operaciones; MIS produce reportes periódicos; DSS apoya consultas particulares.
El nivel estratégico depende de la calidad de los datos y reportes previos.
La aplicación asignada debe analizarse por su propósito, alcance y problemas.
