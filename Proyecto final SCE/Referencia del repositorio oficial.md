## Actualizar la referencia antes de un envío

1. Consultar `develop` y anotar su nuevo commit si cambió.
2. Revisar qué PR se integraron, cuáles recibieron observaciones y qué archivos coinciden con el paquete propio.
3. Releer las secciones afectadas y adaptar únicamente la aportación. No pegar un README completo de una versión anterior.
4. Anotar el commit base y las decisiones nuevas en el paquete correspondiente.
5. Comprobar la incorporación oficial antes de cambiar su estado a **Integrado**.
