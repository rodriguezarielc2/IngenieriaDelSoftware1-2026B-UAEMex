# Proyecto final SCE

Esta carpeta reúne el trabajo de planeación y las propuestas para el sistema de control escolar de Ingeniería de Software I. El propósito es construir una documentación coherente: explicar qué problema se atiende, delimitar el alcance y relacionar requisitos, datos y modelos de los distintos módulos.

Aquí preparamos aportaciones para que el equipo las revise. La entrega oficial se integra mediante PR en [el repositorio del profesor](https://github.com/wichis/26b_is1_proyecto-final), rama `develop`.

## Cómo se organiza el trabajo

El plan establece las tareas y sus dependencias. El diagnóstico identifica faltantes de la versión revisada, y la encuesta aporta testimonios para discutir necesidades. Las propuestas reúnen cambios concretos y textos para preparar su envío al profesor.

Cada equipo conserva la responsabilidad de sus módulos. Las tareas compartidas, los responsables propuestos y las decisiones de diseño requieren acuerdo del grupo. La fecha oficial de entrega sigue por confirmar.

## Antes de aportar

Consultar el plan y los cambios ya propuestos, acordar la tarea con los equipos afectados y seguir las pautas de presentación. Una propuesta preparada aquí todavía debe revisarse y enviarse; se considera integrada cuando su incorporación a `develop` está confirmada.

Para trabajar con un asistente de IA, comenzar por [AGENTS.md](../AGENTS.md), que indica cómo leer las instrucciones y la memoria del proyecto.
