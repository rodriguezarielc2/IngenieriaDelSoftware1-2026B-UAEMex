# Clase 14 — Git y GitHub

## Contexto complementario

El flujo de colaboración comprende clonar un repositorio, revisar remotos y ramas, actualizar cambios, crear una rama, registrar commits y subirlos. También se practica corregir la configuración del remoto, atender rechazos de permisos y abrir una solicitud de incorporación para integrar cambios. Los datos concretos de cuentas y equipos no forman parte de esta guía.
